# AI 使用与个人贡献记录

本项目允许 AI 辅助；本文按实际过程区分贡献，不将 AI 生成内容冒充个人独立完成。

## 已知实际贡献

| 参与者 | 已实际完成 |
|---|---|
| 候选人 | 提供题目及交付要求、选用第一题、创建 GitHub 仓库、选择 DeepSeek 作为真实模型接口 |
| Codex | 梳理需求、设计工具循环与确认边界、生成代码/合成数据/测试/文档、执行本地验证并保存实际证据 |

候选人后续亲自阅读、修改、运行和验证的内容，须由候选人按事实补充；当前没有把未发生的操作写成“个人优化”。AI 是开发辅助工具；运行时 `--model deepseek` 调用 DeepSeek，`--model mock` 运行确定性替身，两者不同。

## AI 辅助范围

辅助生成 Python 工程、原生工具调用接口、SQLite 事务、合成场景、unittest、验收脚本、CI 配置及五份文档。AI 查询了 DeepSeek 官方 Tool Calls / Chat Completions 文档，以检查模型名称与协议参数。没有复用题目示例仓库的预设决策日志。

本次生成后的修改包括：移除官方当前接口文档未列出的 `parallel_tool_calls` 参数；使用执行器事实构造报告；确认仅绑定素材与精确替代时间；草稿保存前二次检查数据库冲突；以数据库唯一键处理并发和不同 request_id 的重复提交。

## 验证记录

真实执行结果见 [测试输出](../examples/test-results.txt) 和 [离线验收汇总](../examples/mock/summary.json)。44 项测试通过，16 个 Mock 场景通过。真实模型未运行的状态见 [评估文档](03-evaluation.md)，不以源码存在代替效果验证。

没有在仓库中保存 API 密钥；`.env`、本地数据库和运行临时文件均忽略。业务资料全部为合成。AI 没有代替候选人完成答辩理解或个人学习记录。
